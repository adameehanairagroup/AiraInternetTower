# Overview
Internet = IP addressing + routing (BGP) + physical links + peering. Sockets (TCP/UDP) are only
the application-side door. This repo covers the pieces a community can build in the open:

1. Application code (sockets)  2. Radio access (4G/5G, Wi-Fi mesh)  3. Core/gateway  4. Monitoring

What a community still has to obtain: **upstream bandwidth** (K-FON / BharatNet / ISP), **spectrum**
(licensed or licence-free bands), **power**, **sites**.
